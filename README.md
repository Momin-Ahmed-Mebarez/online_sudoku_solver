<h1 align="center">An online sudoku solver</h1>
<p align="center">A sudoku solver for INE eJDS project that I expanded to solve puzzles from sudokubliss</p>

## Installation
```bash
git clone https://github.com/Momin-Ahmed-Mebarez/online_sudoku_solver.git
cd online_sudoku_solver
pip install -r requirements.txt
```

## Usage
```bash
python main.py
```
Pressing any button will start the solver, make sure the webpage is fully visible or the solver will fail. Check note


## Note
In sudokubliss make sure to disable automove as it messes with the solver. You can found it under See more options -> Game assistance
